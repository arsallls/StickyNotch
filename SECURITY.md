# Security policy

If you find a security issue in StickyNotch, please report it privately using GitHub's
**[Report a vulnerability](https://github.com/arsallls/StickyNotch/security/advisories/new)** form
rather than opening a public issue.

Please include what you found, how to reproduce it, and which version you're on (Settings → About).

Issues in third-party components (listed in [THIRD_PARTY_LICENSES](THIRD_PARTY_LICENSES)) are best
reported to their maintainers as well.
